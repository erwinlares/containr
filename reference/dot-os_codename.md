# Posit Package Manager codename for an Ubuntu release

Posit Package Manager codename for an Ubuntu release

## Usage

``` r
.os_codename(os_version)
```

## Arguments

- os_version:

  Character. An Ubuntu release, e.g. `"24.04"`.

## Value

A character string, e.g. `"noble"`, or `NA_character_` for a release
this package has no codename for.
